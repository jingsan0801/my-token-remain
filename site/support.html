Support

How can we help?

MyTokenRemain has no account system. Support is handled through public issue reports. Never send passwords, access tokens, API keys or cookies.

Open an issue

Include these details

  • macOS version and Mac model.
  • MyTokenRemain version (Settings › About).
  • The affected provider and the exact visible message.
  • Steps to reproduce, with secrets redacted.

A card says "Login not detected"

MyTokenRemain never refreshes tokens; it only reads the sign-in state each tool saves. Sign in again in that tool and use it once. Some tools, such as Antigravity, must be opened and used once before their credentials are written to disk.

Claude quota without the Claude Code CLI

Paste your own claude.ai sessionKey or Cookie into the Claude row on the Data Sources page. Once verified it is stored only in your Mac's Keychain. Removing the cookie returns the card to the local Claude Code login.

A card is labeled "third-party API"

When Claude Code uses a custom ANTHROPIC_BASE_URL, or Codex uses a custom base_url, the quota comes from the API actually serving you and the card names it. If you use an official login and still see this label, open an issue with the redacted configuration.

WebDAV config sync

Sync is off by default. When enabled it uploads a plaintext JSON payload over HTTPS to the server you configure; the password is stored in the Keychain. If the upload fails, check the URL, credentials and certificate; the app keeps local data unchanged.

Where are token counts, cost estimates or Trends?

They are removed in this fork, together with the iPhone, Apple Watch and widget clients. Only official quota windows and reset countdowns are shown. If you need those features, use the upstream TokenRemain release.

Uninstall

defaults delete com.jingsan0801.mytokenremain
rm -rf ~/Library/Application\ Support/com.jingsan0801.mytokenremain

Pasted keys can be removed in Keychain Access by searching for com.jingsan0801.mytokenremain.

支持

我们能帮你什么？

MyTokenRemain 没有账号系统，问题通过公开 issue 处理。请勿发送密码、访问令牌、API Key 或 Cookie。

提交 issue

请附上这些信息

  • macOS 版本与 Mac 机型。
  • MyTokenRemain 版本（设置 › 关于）。
  • 出问题的服务与界面上完整的提示文字。
  • 复现步骤（请先脱敏）。

卡片提示「未检测到登录」

MyTokenRemain 从不刷新 token，只读取工具自己保存的登录状态。到对应工具里重新登录并正常使用一次即可；Antigravity 等工具需要先打开使用一次，凭证才会写到本机。

没有 Claude Code CLI 时查看 Claude 额度

在「数据来源」页的 Claude 行粘贴你自己的 claude.ai sessionKey 或 Cookie，验证成功后只保存在本机钥匙串。移除 Cookie 即恢复读取本地 Claude Code 登录。

卡片标注「第三方 API」

当 Claude Code 设置了 ANTHROPIC_BASE_URL，或 Codex 配置了自定义 base_url 时，额度来自实际提供服务的 API，卡片会注明来源。如果使用官方登录却被这样标注，请附脱敏后的配置提交 issue。

WebDAV 配置同步

同步默认关闭。开启后通过 HTTPS 向你配置的服务器上传一份明文 JSON；密码保存在钥匙串。若上传失败，请检查地址、凭证与证书；应用不会改动本地数据。

Token 统计、成本估算与趋势页去哪了？

这些功能与 iPhone、Apple Watch 和小组件客户端已在本 fork 中移除，只保留官方额度窗口与重置倒计时。如需这些功能，请使用上游 TokenRemain 发布版。
