Privacy Policy

MyTokenRemain is a local-only, macOS quota viewer. Provider credentials remain on your Mac. There is no TokenRemain account, no telemetry, no cloud sync and no mobile companion in this fork.

Effective October 22, 2026Personal fork of TokenRemain

Summary

The app reads the selected AI coding tools and provider services already configured on your Mac, and queries each provider's official API for quota information. It does not upload credentials, usage statistics or account data to any server operated by this project.

Data processed on the Mac

Depending on the providers enabled, the app may read local configuration files, local databases, command-line output, localhost services, or credentials already stored by those tools. It may send authenticated requests directly to a selected provider to retrieve quota information.

Provider credentials — including access tokens, API keys, cookies and account sessions — remain on the Mac. The app does not refresh third-party OAuth tokens, write credentials back to those tools, upload prompts, projects, conversations, account names or request history, and does not read browser cookie stores.

Quota caches, account profiles, preferences and (optionally) pasted secrets are stored locally. Pasted API keys and cookies are kept in the macOS Keychain and are excluded from iCloud Keychain sync.

What this fork does not do

  • No local token counting, session-log parsing, cost estimates or usage history (ccusage was removed).
  • No model-pricing table downloads and no exchange-rate requests.
  • No iCloud/CloudKit publishing, no Local Network sync listener, no iPhone, iPad, Apple Watch or widget clients.
  • No AI Feed polling, no push-notification registration and no analytics SDKs.
  • No automatic update checks.

Network activity

Requests go only to the official endpoints of the providers you have enabled, in order to read quota or account balance. The app also reads the public status endpoints of status.openai.com and status.claude.com to show service status. These requests contain the credentials required by that provider and no usage history.

If you enable the optional WebDAV configuration sync, the app connects only to the server URL you enter and uploads a JSON payload containing tracked providers, account metadata and app-owned credentials over HTTPS. The payload is not encrypted by the app. It stays on your own server; disabling the feature stops further uploads.

Data retention and deletion

Local caches and preferences live in your home folder and are removed when you delete the app's support folder and preferences. Pasted keys can be deleted in Keychain Access. Data uploaded to your own WebDAV server is controlled and deleted by you.

Contact

Questions or reports: open an issue at github.com/jingsan0801/my-token-remain. Never include passwords, access tokens, API keys or cookies in a report.

隐私优先

隐私政策

MyTokenRemain 是一个只在 macOS 本地运行的额度查看器。服务商凭证始终留在你的 Mac 上。本 fork 没有 TokenRemain 账号、没有遥测、没有云端同步，也没有移动端伴侣。

生效日期：2026 年 10 月 22 日TokenRemain 的个人 fork

概要

应用读取你在 Mac 上已经配置好的 AI 编码工具与服务，并直接向各服务商官方 API 查询额度。它不会把凭证、用量统计或账号数据上传到本项目运营的任何服务器。

在 Mac 上处理的数据

视启用的 provider 而定，应用可能读取本地配置文件、本地数据库、命令行输出、localhost 服务，或这些工具自己保存的凭证；也可能带着该服务所需的认证直接请求官方接口以获取额度。

服务商凭证（访问令牌、API Key、Cookie、账号会话）始终留在 Mac 上。应用不会刷新第三方 OAuth token、不会写回凭证，也不会上传提示词、项目、对话、账号名或请求历史；从不读取浏览器自身的 Cookie 存储。

额度缓存、账号资料、偏好设置与（可选的）手动粘贴密钥保存在本机。粘贴的 API Key 与 Cookie 存入 macOS 钥匙串，并禁止同步到 iCloud 钥匙串。

本 fork 不做的事

  • 不做本地 Token 统计、不解析会话日志、不估算成本、不保留用量历史（ccusage 已移除）。
  • 不下载模型价格表，不请求汇率。
  • 不做 iCloud/CloudKit 发布，不监听局域网端口，不包含 iPhone、iPad、Apple Watch 与小组件客户端。
  • 不轮询 AI 动态、不注册推送通知、不集成任何分析 SDK。
  • 不检查自动更新。

联网行为

请求只发往你已启用服务的官方接口，用于读取额度或账户余额。应用还会读取 status.openai.com 与 status.claude.com 的公开状态接口以展示服务状态。这些请求只携带该服务要求的认证信息，不包含用量历史。

如果你开启可选的 WebDAV 配置同步，应用只会连接你填写的服务器地址，并通过 HTTPS 上传一份包含已追踪 provider、账号元数据与应用自有凭证的 JSON。载荷本身未加密，保存在你自己的服务器上；关闭该功能即停止上传。

数据保留与删除

本地缓存与偏好位于你的主目录，删除应用的支持目录与偏好即清除。粘贴的密钥可在「钥匙串访问」中删除。上传到你自己的 WebDAV 服务器的数据由你控制与删除。
