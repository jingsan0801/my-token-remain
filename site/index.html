Features

Quotas, not analytics

This fork deliberately keeps one job: show how much official quota is left and when it resets. Everything below is real, live data read from each tool.

QUOTAS

Official windows only

Every provider's own windows — 5-hour, 7-day, monthly, model-pool — with segment bars, reset countdowns and freshness.

ACCOUNTS

Multiple accounts

Each signed-in account gets its own row. Enable, pause, rename accounts and update credentials on one page.

SURFACES

Menu bar, Dock and floating window

Choose which apps appear in the menu bar capsule and on the Dock icon's two meters; keep a floating window across Spaces.

WEBDAV

Optional WebDAV config sync

Copy account configuration and keys between Macs through a WebDAV server you control. Off by default, plaintext payload over HTTPS.

PRIVACY

Read-only credentials

Never refreshes or writes provider tokens. Background reads keep Keychain prompts quiet; pasted keys stay in the local Keychain.

LOCAL

No token or cost tracking

No ccusage, no session-log parsing, no price or exchange-rate requests. Quota snapshots and settings are cached locally.

Privacy

Credentials never leave your Mac

This fork has no server of its own. Quota queries go directly to each provider; the only optional outbound destination is a WebDAV server you configure.

Read-only by design

Provider tokens are read through one controlled entry point, never refreshed, written back or migrated.

Local storage only

Quota caches, account profiles and preferences stay in your home folder; pasted secrets stay in the Keychain.

No tracking

No TokenRemain account, no analytics SDK, no telemetry, no push registration.

No cloud sync

The iPhone, Apple Watch, widgets and iCloud publishing paths of the upstream app are removed.

Build & install

Build it yourself

This fork ships no DMG and no auto-updater. Build locally with Xcode's Swift toolchain; the script installs a single MyTokenRemain.app into ~/Applications.

USAGEDOCK_INSTALL_DIR="$HOME/Applications" \
USAGEDOCK_SIGNING_IDENTITY="Apple Development: …" \
bash ./script/build_and_run.sh

Requires macOS 14+ and Xcode 16 or later. Without an Apple Development identity, set USAGEDOCK_ALLOW_ADHOC_SIGNING=1; Keychain approvals will not survive rebuilds.
